# Hustle Academy

A storefront for a digital-skills course business, selling three tracks to a mobile-first Nigerian audience: Social Media Marketing, Make Money With AI, and Affiliate & Dropshipping.

**Live site:** https://hustleacademic.netlify.app/

![Screenshot](docs/screenshot.png)

## What I built
- Three course tracks with tiered Self-Paced and VIP pricing in Naira
- Paystack checkout
- A self-service FAQ covering payment, refunds and access, to reduce support questions
- Mobile-first layout

## Tech
HTML, CSS, JavaScript, Paystack. Deployed on Netlify.

## Run locally
```bash
git clone <this-repo-url>
cd <repo-folder>
npx serve .
```
Add your own Paystack public key in the config before testing checkout.
